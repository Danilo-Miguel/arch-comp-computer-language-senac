# Conversão de Base e Tabela ASCII

Este dojo pratica conversão entre hexadecimal, decimal e binário, além
de leitura e escrita de caracteres em código ASCII — as mesmas
habilidades cobradas no Check Point 1 de Arquitetura de Computadores.

Cada exercício apresenta um problema de conversão (tabela de valores,
endereço de memória, byte de código de máquina ou uma palavra/nome em
ASCII). Você deve:

1. Fazer os cálculos (no papel, mostrando as contas, e opcionalmente
   conferindo com `python3` no terminal, ex.:
   `python3 -c "print(int('1C', 16))"`);
2. Salvar as respostas, no formato pedido em cada enunciado, no
   arquivo `/home/hacker/resposta.txt`;
3. Rodar `/challenge/check`, que confere sua resposta e libera a flag
   se estiver correta.

Os 20 exercícios são avaliados **individualmente** (cada um é um
"hacking" separado), então cada um aparece separadamente na tabela de
colocação. Faça os 20 para completar o dojo.
